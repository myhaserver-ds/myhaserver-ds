**Home automation enthusiast. Infrastructure tinkerer. Professional button-pusher. Amateur chaos engineer.**

### 🧠 What's running in the asylum?

- 🏠 **Home Assistant** — Because apparently light switches weren't complicated enough.
- 🌐 **Cisco networking** — Enterprise-grade infrastructure for an embarrassingly small number of humans.
- 🖥️ **Proxmox** — Virtualizing things that probably didn't need virtualizing.
- 🍓 **Raspberry Pi** — Small computer, disproportionately large responsibilities.
- 📡 **Wi-Fi infrastructure** — Yes, the house has a wireless controller. No, I'm not sorry.
- 🔐 **Network security** — Trust is earned. VLANs are mandatory.
- ⚙️ **Industrial automation** — Because sometimes an appliance needs a PLC.
- 💾 **Backups** — If it doesn't exist in multiple places, it doesn't exist.

### 🔬 Current experiments

Making Home Assistant increasingly aware of everything happening in the house.

Collecting network telemetry, monitoring infrastructure, integrating devices that were never supposed to cooperate, and occasionally convincing obsolete hardware to earn its electricity.

**Operating philosophy:**

> If it works, automate it.
>
> If it breaks, troubleshoot it.
>
> If it's obsolete, find another use for it.
>
> If it's simple, we're probably not finished overengineering it.
